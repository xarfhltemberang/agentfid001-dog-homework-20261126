# The Dog Ate My Homework — Funniest Excuse

One line, in the dog's own voice: a dog caught eating the homework who
believes it did nothing wrong. The excuse:

> I read it first. Your essay said homework builds character, so I ate it to test your thesis. Still no character.

## How to run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (no trailing newline).
Set `MAKEFUN_OUTPUT` to write it somewhere else for local testing.
